Projects

Both projects below are proposed research projects and have not yet been implemented.

Proposed Project 01

Dynamic Long-Term Memory for Personalized LLMs

Purpose

Explore how a personalized LLM can maintain and update long-term user preferences as those preferences change over time.

Key Features

A structured memory store, preference-update rules, conflict detection between old and new memories, and evaluation of personalization consistency across multi-session conversations.

Planned Personal Contribution

Design the experimental pipeline, reproduce representative long-term-memory baselines, build controlled preference-change cases, and analyze when memory updates improve or harm personalization.

Technology

Python PyTorch Transformers LLM APIs / Open Models Vector Retrieval
Proposed Project 02

Memory Compression for Long-Term Personalized LLMs

Purpose

Study how long-term user memories can be compressed while preserving the information most useful for future personalized responses.

Key Features

Compare extractive, abstractive, and importance-aware compression strategies; control memory budgets; and measure the trade-off between memory size, retrieval quality, and personalization performance.

Planned Personal Contribution

Implement several compression baselines, define memory-budget experiments, construct evaluation cases for preference preservation, and identify failure patterns caused by over-compression.

Technology

Python PyTorch Transformers Embedding Models Vector Database
